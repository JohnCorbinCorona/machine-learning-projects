# Machine Learning Projects

Two Jupyter notebooks from a machine learning course. Each includes executed results and figures.

| Notebook | Analysis | Input files |
| --- | --- | --- |
| [Employee Turnover](Employee_Turnover_Project.ipynb) | Turnover classification, SMOTE, and retention risk zones | `HR_comma_sep.csv` |
| [Rolling Stones Song Cohorts](Rolling_Stones_Song_Cohorts.ipynb) | Spotify audio features, PCA, and track clustering | `rolling_stones_spotify.csv` |

## Run locally

Use Python 3.13 and install the dependencies with `python -m pip install -r requirements.txt`. Place the relevant course CSVs beside the notebooks, open the notebook in Jupyter, and run all cells. The executed notebooks can also be read directly on GitHub.
